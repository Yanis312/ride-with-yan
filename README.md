# Ride with Yan

Application tablette bilingue (FR/EN) pour passagers de taxi/VTC : divertissement, actualités, question du jour, mini-boutique.

## Structure

| Dossier | Contenu |
|---|---|
| `app/` | Application tablette Flutter (Android + Web) |
| `docs/` | Plan de projet et documentation |

À venir : `api/` (ASP.NET Core), `admin/` (dashboard web).

## Lancer l'app

```bash
cd app
flutter pub get
flutter run -d chrome
```
